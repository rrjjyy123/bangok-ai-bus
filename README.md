# 반곡 AI 버스 훈련소

세종 반곡초 6-8 실과 공개수업(2026. 10. 20., [6실05-05])용 3D 웹 게임.
실제 반곡동 지도(OpenStreetMap)에서 사람·탈것 사진을 모아 자율주행 셔틀 '누비'(🎮 가상)의 이미지 분류 AI를 학습시키고, BRT 도로에서 시험 운행하며 **데이터 편향과 AI 윤리**를 스스로 발견한다.

- 학생 주소: **https://bangok-ai-bus-1020.web.app**
- 선생님 화면: **https://bangok-ai-bus-1020.web.app/teacher.html**

## 수업 진행 순서 (선생님)
1. 전자칠판에서 **선생님 화면** → `＋ 새 수업 방 만들기` → 4자리 방 코드가 크게 나온다.
2. 학생 태블릿: 학생 주소 → `탐험 시작하기` → 이야기 → **방 코드 입력** → 모둠 선택.
   같은 모둠 기기끼리는 사진 앨범이 실시간으로 합쳐진다. 새로 고침해도 `이어서 하기`로 돌아온다.
3. 선생님 화면 버튼(위에서 차례로)
   | 버튼 | 하는 일 |
   |---|---|
   | 📖 오프닝 | 큰 화면에 한결 연구원·누비 대사(화면을 누르면 다음) |
   | ③ 학습·시험 운행 허용 | 누르기 전에는 학생이 사진만 모을 수 있다 |
   | 🚧 지도 전체 개방 | 공사 펜스가 사라지고 사진 +20장(되돌릴 수 없음) |
   | 🔁 데이터 거래소 열기 | 학생 화면 오른쪽 위에 `거래소` 버튼 → 다른 모둠 사진 가져오기 |
   | 🗳 책임 투표 시작/마감 | 학생 기기에 투표 창이 뜨고, `책임 투표` 탭에 실시간 막대 |
   | 🎬 에필로그 | 학생 기기와 큰 화면에 마지막 대사 |
   | ✋ 모두 멈춤 | 학생 화면을 잠시 가린다(다시 누르면 풀림) |
4. 탭: **모둠 현황**(기기 수·사진 수·학습 여부·1차/2차 점수) · **우리 반 데이터 지도**(모둠 × 대상 종류, 0장은 빨간 칸) · **점수 비교** · **윤리원칙 카드** · **책임 투표**
5. 수업이 끝나면 `설정` → **이 방 삭제하기**. 학생 기기는 자동으로 '혼자 하기'로 바뀐다.

- **안정 모드**(`설정`의 숨은 스위치): 돌발 상황 때 실제 판단 대신 '우리 데이터에 같은 대상(밤이면 밤 사진)이 있었는지'로 시험 결과를 정한다.
- 인터넷이 안 되면 학생은 `방 없이 혼자 해 보기`로 모든 활동(촬영·학습·시험 운행·AI 속마음·윤리원칙)을 할 수 있다. 이때는 메뉴에서 지도 개방을 직접 한다.
- 선생님 권한은 방을 만든 브라우저에 저장된다. 수업 때 쓸 컴퓨터에서 방을 만든다.

## 지키는 것
- 🎮 게임(가상 인물·이야기)과 📰 진짜 자료를 화면에 구분해 표시. 실존 상호명 없음. 지도 출처(© OpenStreetMap 기여자, ODbL) 표기.
- 학생 이름·얼굴·위치를 수집하지 않는다(태블릿 카메라 사용 안 함). 서버에는 게임 속 3D 장면 썸네일, 특징값, 이름표, 윤리 카드 이유(120자, "이름은 쓰지 않아요" 안내)만 저장.
- 보안 규칙(`firestore.rules`): 익명 로그인 필수, 방 설정·삭제는 만든 선생님만, 사진 크기 제한, 기기·투표·윤리 카드는 자기 것만. (실서버에서 다른 사용자의 방 설정 변경·삭제·남의 기기 흉내가 막히는 것 확인)

## 리허설 점검 결과(자동 측정, 사진 36장·시험 12장면·4회 평균)
| 데이터 | 맞힌 장면 |
|---|---|
| 한 구역만(1·3·5모둠) | 5.3 · 7.5 · 3.5 / 12 |
| 여러 구역 골고루 | 9.3 / 12 |
| 1모둠 + 다른 구역 사진 25장(거래소·개방 후) | 8.9 / 12 (+3.6) |

브라우저 콘솔에서 `__dbg.evalDrive()`로 지금 학습된 누비를 시험 코스 12장면에 바로 돌려 볼 수 있다.

## 개발
정적 파일(빌드 없음, ES 모듈 + importmap). 로컬 실행: `npx serve .`
- `src/main.js` 게임 흐름·촬영·학습·시험 운행·AI 속마음·방 참여/동기화
- `src/net.js` Firebase 연결(익명 로그인, Cloud Firestore 서울 리전), 특징값 압축 · `src/net-mock.js` 로컬 테스트용 가짜 서버(`?mock=1`, localhost만)
- `src/teacher.js` + `teacher.html` 선생님 화면
- `src/ml.js` 자체 머신러닝(HOG+색 특징 → 작은 신경망)
- `src/world.js` · `src/npc.js` 지도 3D·NPC, `src/config.js` 구역·장면·대사·윤리원칙·투표
- `data/bangok.json` 반곡동 지도(OSM) — `python3 tools/osm_to_json.py map.osm data/bangok.json`

배포(Firebase 프로젝트 `bangok-ai-bus-1020`):
```
firebase deploy --only hosting,firestore
```
